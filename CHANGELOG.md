# Changelog

## 0.3.0

Viewing is a method of the workflow declaration: `Workflow(...).view()`. The separate package-level `view` function is removed. Command-line flags and workflow behavior remain available through the method.

## 0.2.0

First standalone release. Provides process-scoped GaussView sessions, input comparisons, native menu and control discovery, enabled/checked state inspection, alignment and window placement, animation and result helpers, live ESP scale analysis, structured logging and Sphinx documentation. See the coverage guide for incomplete and unverified native controls.
